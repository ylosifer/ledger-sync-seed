## Resolution

### 1. Reproduction
Reproduced via `SelfCheck` and new regression tests in `AmountsTest.java`. The `Amounts.first(...)` method returned `92213.10` instead of `5.00` for `"Rs.5 debited from a/c **4821 on 04-07-26 at 07:19 to UPI/WATER CAN. Avl Bal: Rs.92,213.10."`. This produced the exact divergence of `-1,254,130.19` reported in production.

### 2. Root Cause
File: `src/main/java/in/simplifymoney/ledgersync/parse/Amounts.java`, lines 17-18.
The pattern `Pattern.compile("(?:Rs\\.?|INR)\\s*([0-9,]+\\.[0-9]{2})")` strictly required two decimal places. For integer amounts without decimals (e.g. `Rs.5` or `INR 18,000`), the pattern failed to match the transaction amount and matched the next available rupee figure in the string, which was the stated balance (`Avl Bal: Rs.92,213.10`).

### 3. Blast Radius
- **Count:** 44 messages in `fixtures/corpus-a.jsonl` are affected.
- **Rule:** Any message where the transaction amount lacks a decimal point and two decimal places (`\.[0-9]{2}`) fails the amount match, causing the parser to fall through to the available balance (or return null if no balance is quoted).

### 4. Fix & Test
Updated `Amounts.java` to use `(?:Rs\\.?|INR)\\s*([0-9,]+(?:\\.[0-9]{2})?)` and scale integer amounts to 2 decimal places. Added failing test cases in `AmountsTest.java` that now pass.

### 5. Five Lines for Incident Channel
- **What broke:** Amounts.java regex required two decimal places, skipping integer amounts (e.g. "Rs.5") and matching the account balance ("Avl Bal: Rs.92,213.10").
- **How found:** Traced app.log message m-00004-9c11ae where Rs.5 was parsed as 92213.10, matching the exact -1,254,130.19 divergence alert.
- **Who affected:** 44 messages across HDFC and ICICI accounts containing whole rupee amounts without decimal places (e.g. Rs.5, INR 18,000).
- **Fix applied:** Updated AMOUNT and BALANCE regex to `(?:Rs\\.?|INR)\\s*([0-9,]+(?:\\.[0-9]{2})?)` with BigDecimal scale 2 normalization.
- **Why it cannot recur:** Added automated regression tests for integer rupee and INR formats to CI test suite.
